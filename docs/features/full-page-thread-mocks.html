Show a thread in the entire page

Today a room thread opens in the right panel (about 320–420px wide). The fork's Threads mode (#/threads) already shows threads wide, but only from its own cross-room list. These mocks show ways to give any thread the whole page. Purple dashed outlines mark new controls.

1. Where does the expanded thread go?

Decided: A (fill the room area), full width, ⤢ button in the thread header only, own URL with Back collapsing.

Pick a layout, then press the new ⤢ expand button in the thread header. Use the browser ← to see what Back does.

3. URL and Back

Shown in the address bar above. Proposal: the expanded state has its own URL so a reload or a shared link reopens it, and browser Back collapses it.

State URL
Room, thread in right panel #/room/!abc:server (unchanged)
Thread expanded (A or B) #/room/!abc:server/thread/$rootEventId
Thread expanded on a reply #/room/!abc:server/thread/$rootEventId/$replyEventId

4. Room header buttons while the thread is expanded

Decided: X. The thread collapses back into the right panel.

The thread is expanded (layout A, full width). Click ⓘ Room info, 👥 People or ≡ Threads in the room header, then pick another thread in the list.

●●●

5. Scroll position when expanding or collapsing

Decided: K. Keep the same message in view.

The thread moves to a different place in the page, so its timeline is rebuilt. Scroll the thread up to an older message, then press ⤢ / ⤡.
