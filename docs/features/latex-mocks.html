5 · The on/off switch

            

                One setting controls both sending (maths detection in the composer) and showing (KaTeX rendering of
                received maths). It is on by default; deployments can still turn it off with
                features.feature_latex_maths in config.json.
            

            

                

                    
Option A: Settings → Labs → Messaging

                    

                        

                            
Render LaTeX maths in messages

                            

                                Type $…$ or \(…\) for inline maths and $$…$$ or \[…\] on their own lines for display
                                maths.
                            

                        

                        
                    

                    

                        Same pattern as Interactive messages. Hidden when the deployment has no Labs tab.
                    

                

                

                    
Option B: Settings → Preferences → Composer

                    

                        
Enable Markdown

                        
                    

                    

                        

                            
Render LaTeX maths in messages

                            

                                Type $…$ for inline maths and $$…$$ on their own lines for display maths.
                            

                        

                        
                    

                    

                        A real setting, not a lab. Always visible. Needs a rename/migration of the labs flag.
